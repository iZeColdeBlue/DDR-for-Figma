01
A GitHub account

A free home on github.com. It stores everything you sync.

02
A repository

A folder on GitHub that keeps every version of your docs.

An access token

A password-like key. It lets this plugin write to your repository, and nothing else.

### Create an access token

The plugin needs a key to write to your repository. Create a fine-grained token that can only touch that repo.

github.com/settings/personal-access-tokens/new

### Create a branch(optional)

A branch is a parallel copy of your repository. Docs saved on their own branch stay apart from other work until you merge them. If you work alone, skip this and docs go to the default branch.

github.com/your-name/design-docs
Branch menu⎇ main ▾1
New branchdesign-docs2
Create branch
01Open your repository on GitHub and click the branch menu, it says main
02Type a name, for example design-docs, and choose Create branch
03Type the same name in the field below. Skipping GitHub is fine too: a new name is created on your first sync
Full guide with screenshots
Leave it empty to save to the default branch.
