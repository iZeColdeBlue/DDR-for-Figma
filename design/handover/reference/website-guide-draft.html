Create an access token
A token lets the plugin write to your repository. Make a fine-grained token for that one repository. About 3 minutes.
01
Open GitHub Settings, then Developer settings, then Fine-grained tokens.
[Screenshot: menu path]
02
Choose Only select repositories and pick your repository.
[Screenshot: repository access, highlighted]
03
Set Contents to Read and write. Generate and copy the token.
[Screenshot: permissions, highlighted]
Copy the token now. GitHub shows it only once. Then return to Figma and paste it. ← [Back to plugin]
